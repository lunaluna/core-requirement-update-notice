== Description ==

wp.org の update-check API は、新バージョンが要求する WordPress バージョンをサイトが満たしていない場合、そのプラグイン／テーマを `update_plugins` / `update_themes` トランジェントの `response` ではなく **`no_update`** に入れて返します（`new_version` にはインストール済みより新しい版が入ったまま）。

WordPress コアの表示系は `response` しか見ないため、更新行が 1 行も描画されず、**新しい版が出ていること自体が管理画面から見えなくなります**。一方、PHP 要件を満たさない場合は `response` に入ったまま返るので、コアは赤い警告を表示します。同じ「要件を満たさない更新」でありながら、PHP 要件なら警告が出て、WordPress 要件なら無言で消える、という差があります。

このプラグインはその差を埋め、WordPress 要件を満たさない更新にも PHP 非互換時と同等の警告を表示します。放置すると「更新が来ていない」のか「来ているが適用できない」のかを区別できず、サイトを古いまま運用し続ける原因になります。

設定画面はありません。有効化した時点で動作します。

= 表示される場所 =

* **プラグイン一覧**：対象プラグインの行の下に、コアの更新行と同じ見た目で `notice-error` の警告行を出します。更新は実行できないため「今すぐ更新」リンクは表示しません。コアが更新行を出しているケースでは、そのメッセージ末尾に警告を追記し、`notice-warning` を `notice-error` に差し替えたうえで「今すぐ更新」を取り除きます。ネットワーク管理画面にも対応しています。
* **テーマ一覧**：コア側に既にある「新しいバージョンが利用可能ですが、現在使用中の WordPress のバージョンでは動作しません」の表示に乗せます（`wp_prepare_themes_for_js` でデータを立て直すだけで、自前のマークアップは追加しません）。
* **更新一覧**：「WordPress の更新が必要なプラグイン」「WordPress の更新が必要なテーマ」のセクションを追加し、コアの節順（プラグイン → テーマ → 翻訳）に馴染む位置へ並べ替えます。コアが更新行を出しているものは、注記を追加したうえでチェックボックスを外し、一括更新に含まれないようにします。
* **自動更新**：`auto_update_plugin` / `auto_update_theme` で対象外にします。`Plugin_Upgrader::bulk_upgrade()` が `is_wp_version_compatible()` で事前に弾くため、抑止しないと毎回失敗し続けます。

= 既知の制限 =

* マルチサイトのネットワーク管理テーマ一覧は未対応です（プラグイン一覧は対応済み）。
* `Requires at least: 5.2` は `is_wp_version_compatible()` の追加バージョンに合わせた目安で、実際に動作確認したのは 6.8.8 のみです。
* 更新一覧のセクション位置は出力バッファに依存するため、他のプラグインが `update-core.php` の出力を横取りしている場合はページ末尾に残ることがあります（表示自体は消えません）。

== Installation ==

1. このプラグインを**ディレクトリごと** `wp-content/plugins/core-requirement-update-notice/` に配置する。メインファイルは `includes/` 以下を読み込むだけなので、単体で置いても動作しません。
2. WordPress の「プラグイン」画面で **Core Requirement Update Notice** を有効化する。

設定は不要です。以降は GitHub Releases からの自動アップデートが有効になり、通常のプラグイン更新フロー（更新通知 → ワンクリック更新）で更新できます。

== Frequently Asked Questions ==

= 設定画面はありますか？ =

ありません。有効化した時点で動作します。

= 警告が出たらどうすればよいですか？ =

WordPress 本体を更新してください。更新後は対象のプラグイン・テーマが通常の更新フローに戻り、このプラグインの警告も自動的に消えます。

= 更新ボタンが押せないのはなぜですか？ =

その更新は実行しても失敗するためです。`Plugin_Upgrader::bulk_upgrade()` はコアバージョン要件を満たさない更新を事前に弾きます。このプラグインは押しても無駄なボタンを隠し、代わりに理由を表示します。

= このプラグイン自体は何か記録を残しますか？ =

残しません。オプションも独自テーブルも作らず、既存の更新トランジェントを読むだけです。

= WordPress 本体を更新できない事情がある場合は？ =

警告は表示され続けますが、更新は妨げられません。対象のプラグイン・テーマは現在のバージョンのまま動き続けます。
